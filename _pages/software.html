All of my software is open source: freely licensed, developed publicly on GitHub, and written for mathematicians and biologists alike. Every package is written in Python and comes with its own documentation site and test suite, and most have a graphical interface, so you can use them without writing any code. The packages also fit together: PhyloZoo provides the shared foundation that Squirrel and PaNDA build on.
